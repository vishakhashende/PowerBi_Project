****** Hospitality Revenue Insights Dashboard ******

## Project Overview

This Power BI project analyzes hospitality domain revenue performance using interactive dashboards and data visualization techniques.

The dashboard helps in:

* Revenue analysis
* Booking trend analysis
* Hotel performance tracking
* Occupancy insights
* Business decision-making

---

## Tools Used

* Power BI
* Power Query
* DAX
* CSV Dataset
* Data Modeling

---

## Dataset Files

* dim_date.csv
* dim_hotels.csv
* dim_rooms.csv
* fact_aggregated_bookings.csv
* fact_bookings.csv

---

## Key Insights

* Revenue trends across hotels
* Booking platform analysis
* Occupancy percentage tracking
* Room category performance
* Weekly and monthly business insights
